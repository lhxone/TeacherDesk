# 收集箱

## 使用

1. 从侧边栏、手机底部导航或首页进入“收集箱”，新建信息调查。
2. 填写标题和说明，添加姓名、电话、身份证、年级或附件等字段，也可添加短文本、长文本、数字、日期和单选字段。每个字段可修改名称、提示、必填状态和顺序，单选项可自定义。
3. 保存草稿，或发布后复制链接。任何拿到链接的人均可直接填写，无需注册或登录教师账号。
4. 在“回收结果”查看答卷、下载附件，或导出全部答卷的 CSV。
5. 停止收集后，原链接不能继续填写；重新发布可继续使用原链接。

每份调查最多 50 个字段，其中附件字段最多 5 个；每个附件字段上传 1 个文件，每个文件最多 10 MiB。填写和提交需要联网。

## 数据与权限

- 教师只能管理本人创建的调查、答卷和附件。
- 公开接口只提供已发布表单和提交入口，不提供答卷列表或附件下载。
- 修改表单会增加版本号。打开旧版本的填写者需刷新表单后提交，防止答案与新字段错位。既有答卷保留提交时的字段快照。
- 调查、答卷和附件的 API 响应使用 `Cache-Control: no-store`；Service Worker 对调查读取使用 NetworkOnly。
- 附件保存在现有资源存储根目录的调查命名空间内，复用 Docker 的 `resource-data` 持久卷。下载需登录且强制以附件提供，不以内联网页执行上传内容。
- 匿名提交有请求频率、字段数量和文件大小限制。链接不验证填写者身份，因此不保证每人仅填一次。

## 部署

部署新版本时运行 `cd server && npx prisma migrate deploy`，追加调查、答卷和附件表。不要重置已有数据库。Docker Compose 的 `migrate` 服务会自动应用新增迁移。

备份需要同时包含 PostgreSQL 数据和 `resource-data` 卷；复用现有 `RESOURCE_STORAGE_ROOT` 配置，无需新增存储服务。

如果站点在反向代理或 Cloudflare Access 层统一要求登录，还需让公开填写页面 `/s/*`、对应 `/api/v1/public/surveys/*` 接口及页面静态资源可匿名访问，才能让站外填写者使用链接。
