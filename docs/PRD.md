# 教师工作台（TeacherDesk）产品需求文档 PRD

- 版本：v1.0
- 日期：2026-08-30
- 状态：待评审

---

## 1. 产品概述

### 1.1 背景
中小学教师日常需要处理班级、学生、课表、座位、随机点名分组、成绩统计等大量事务，现有工具零散（Excel + 微信 + 纸质表格），数据无法沉淀与联动。TeacherDesk 目标是把这些高频动作收敛到一个轻量的一体化工作台中。

### 1.2 产品定位
面向**单个教师（班主任 / 任课教师）**的个人效率工具，Web 优先，同时以 PWA 形式提供接近原生的手机端体验（可安装到桌面、离线查看、课堂现场使用）。

### 1.3 目标用户
| 角色 | 典型场景 | 核心诉求 |
|---|---|---|
| 班主任 | 管理 1 个行政班的全部学生 | 学生档案、座位图、日程 |
| 任课教师 | 教多个班的同一学科 | 成绩录入与分析、随机抽签 |
| 备课/教研 | 学期复盘 | 成绩趋势图表、导出 |

### 1.4 设计原则
1. **课堂现场可用**：抽签、点名、座位图必须在手机上单手 3 秒内触达。
2. **数据自持**：教师自己的数据只有自己可见，不做校级多租户复杂权限（v1）。
3. **离线容忍**：PWA 缓存静态资源与最近访问的班级/学生数据，弱网可读。
4. **前后端分离**：后端只提供 JSON API，前端独立部署。

## 2. 范围

### 2.1 V1 范围（本期）
- 用户注册、登录、鉴权（JWT + Refresh Token）
- 班级管理（增删改查、归档）
- 学生管理（增删改查、批量导入、学生标签）
- 日程表（周课表 + 待办事项）
- 座位图（可视化拖拽排座、随机排座、保存多套方案）
- 随机抽签 / 随机分组
- 成绩管理与分析（考试、成绩录入、班级维度与学生维度图表）
- PWA（可安装、离线壳、Service Worker 缓存）

### 2.2 V1 不做（Out of Scope）
- 学校/年级组多级组织与管理员后台
- 家长端、学生端登录
- 消息推送 / 短信通知
- 在线组卷、题库
- 支付与订阅

## 3. 功能需求

### 3.1 账号与鉴权

#### 3.1.1 注册
- 输入：邮箱、密码、显示名称（昵称）。
- 密码规则：8–64 位，至少包含字母与数字。
- 邮箱唯一；密码使用 bcrypt（cost=12）哈希存储。
- 注册成功后自动登录，返回 access token + refresh token。

#### 3.1.2 登录
- 邮箱 + 密码。
- 连续 5 次失败锁定 15 分钟（按邮箱 + IP 计数）。
- 支持"记住我"（refresh token 有效期 30 天，否则 7 天）。

#### 3.1.3 鉴权机制
- Access Token：JWT，HS256，有效期 2 小时，放在 `Authorization: Bearer <token>`。
- Refresh Token：随机 opaque 字符串，哈希后存库，一次性使用（rotation），有效期 7/30 天。
- 登出：撤销当前 refresh token；「登出所有设备」撤销该用户全部 token。
- 所有业务接口必须校验资源归属：`resource.owner_id == current_user.id`，否则返回 403。

#### 3.1.4 个人设置
- 修改昵称、头像、密码。
- 修改密码后强制撤销其他所有 refresh token。

**验收标准**
- AC-1：未携带有效 token 访问任意 `/api/v1/*`（除 auth 路由）返回 401。
- AC-2：用 A 用户 token 访问 B 用户的班级 ID 返回 403，且响应体不泄露该资源是否存在。

### 3.2 班级管理

#### 3.2.1 字段
| 字段 | 说明 | 必填 |
|---|---|---|
| 班级名称 | 如"高二(3)班" | 是 |
| 学科 | 如"数学"，任课教师用 | 否 |
| 学年 | 如"2026-2027" | 是 |
| 颜色标记 | 用于日程表配色 | 否 |
| 备注 | | 否 |
| 状态 | active / archived | 是（默认 active） |

#### 3.2.2 功能
- 列表：卡片视图，显示班级名、学生数、最近一次考试均分。
- 新建 / 编辑 / 归档 / 删除（删除为软删除，级联隐藏学生与成绩）。
- 归档班级默认不在列表显示，可通过筛选查看。

**验收标准**
- AC-3：删除班级后其学生、座位图、成绩记录均不可通过 API 读取，但数据库保留（软删除）。

---

### 3.3 学生管理

#### 3.3.1 字段
| 字段 | 说明 | 必填 |
|---|---|---|
| 姓名 | | 是 |
| 学号 | 班级内唯一 | 否 |
| 性别 | male / female / other | 否 |
| 头像 | 上传或首字母生成 | 否 |
| 联系电话 | 家长联系方式 | 否 |
| 标签 | 多选，如"课代表""需关注" | 否 |
| 备注 | 长文本 | 否 |
| 状态 | active / inactive（转学等） | 是 |

#### 3.3.2 功能
- 学生列表：支持按姓名/学号搜索、按标签筛选、按学号或姓名排序。
- 单个新增 / 编辑 / 删除。
- **批量导入**：粘贴文本（每行一个姓名，可选 `学号,姓名,性别`）或上传 CSV/XLSX；导入前展示预览与冲突提示（学号重复）。
- 批量操作：批量打标签、批量移出。
- 学生详情页：基础信息 + 历次成绩趋势 + 座位历史 + 备注时间线。

**验收标准**
- AC-4：导入 60 行学生数据，重复学号被标红且不写入，其余正常写入。
- AC-5：学生列表在 300 人规模下首屏渲染 < 1s（分页 or 虚拟列表）。

---

### 3.4 日程表

#### 3.4.1 周课表
- 网格视图：横轴周一至周日（可配置是否显示周末），纵轴节次（默认 8 节，可自定义节次数与时间段）。
- 每个课程条目：关联班级（继承班级颜色）、科目、地点、备注。
- 支持按"单周/双周/每周"重复。
- 支持学期起止日期，超出范围不显示。
- 手机端：默认显示"今日"日视图，可左右滑动切换日期；顶部可切回周视图。

#### 3.4.2 待办 / 事件
- 独立于课表的一次性事项（如"周五交作业本""家长会"）。
- 字段：标题、日期时间、关联班级（可空）、是否完成、提醒（仅前端本地提醒，v1 不做推送）。
- 首页展示"今日课程 + 今日待办"。

**验收标准**
- AC-6：设置一节"单周"的课，在双周对应日期不显示。
- AC-7：手机端日视图切换日期无整页刷新，交互 < 300ms。

---

### 3.5 座位图

#### 3.5.1 布局
- 教室布局可配置：行数 × 列数（默认 6×8），支持将某些格子设为「空位/过道」。
- 支持标记「讲台方位」（上/下），视图按教师视角或学生视角翻转。

#### 3.5.2 排座
- 手动：拖拽学生卡片到座位；两个座位互相拖拽即交换。
- 随机排座：一键随机填充，支持约束条件：
  - 固定座位（钉住的学生不参与随机）
  - 指定标签学生优先前排（如"需关注"）
  - 同性别不相邻（可选开关）
- 保存为**座位方案（SeatingChart）**：一个班级可存多套（如"月考版""日常版"），标记其中一套为「当前使用」。

#### 3.5.3 输出
- 导出 PNG / 打印视图（A4 横向）。
- 手机端只读查看 + 点击座位查看学生详情（不支持拖拽，避免误操作）。

**验收标准**
- AC-8：随机排座启用"固定座位"后，被钉住学生位置不变。
- AC-9：座位数 < 学生数时给出明确提示，不允许保存。

---

### 3.6 随机抽签 / 分组

#### 3.6.1 随机点名（抽签）
- 从指定班级抽取 1 或 N 名学生。
- 动效：滚动名字 1.5s 后定格（课堂仪式感）。
- 选项：
  - 「不重复模式」：本轮已抽中的学生不再抽取，直至全部抽完自动重置。
  - 「按权重」：最近被抽中次数越多，权重越低（软性平衡）。
  - 范围过滤：仅在场学生（可临时标记缺勤）、仅某标签。
- 抽签历史记录留存，可在学生详情看到"本学期被抽中 N 次"。

#### 3.6.2 随机分组
- 输入：组数 或 每组人数（二选一）。
- 约束：
  - 指定必须同组 / 必须不同组的学生对（v1 支持"不同组"黑名单）。
  - 按性别均衡（可选）
  - 按最近一次考试成绩均衡（S 型蛇形分配，可选）
- 输出：分组结果卡片列表，可重排、可导出图片、可保存为分组方案。

**验收标准**
- AC-10：不重复模式下连续抽 N 次（N = 班级人数），每人恰好被抽中一次。
- AC-11：按成绩均衡分组时，各组平均分极差 ≤ 全班标准差。

---

### 3.7 成绩管理与分析

#### 3.7.1 考试（Exam）
- 字段：考试名称、班级、科目、考试日期、满分（默认 100）、类型（平时/单元/期中/期末）、备注。
- 一次考试对应一个班级一个科目。

#### 3.7.2 成绩录入
- 表格式录入：左列学生姓名，右列分数输入框，支持 Tab / Enter 快速跳转。
- 支持缺考标记（分数为空 ≠ 0 分，统计时排除）。
- 支持粘贴一列分数批量填充（按当前排序对应）。
- 自动保存草稿，提交后计算并缓存统计量。

#### 3.7.3 班级维度分析
| 图表 | 说明 |
|---|---|
| 分数分布直方图 | 按 10 分一档分桶，可切 5 分档 |
| 等级占比饼图 | 优(≥85%)/良(75–85%)/中(60–75%)/待提升(<60%)，阈值可配 |
| 多次考试均分折线 | 横轴考试时间，纵轴班级均分，可叠加最高/最低/中位数 |
| 关键指标卡 | 均分、最高、最低、中位数、标准差、及格率、优秀率、参考人数 |
| 学生排名表 | 排名、姓名、分数、较上次进退步（箭头 + 名次差） |
| 多班对比柱状图 | 同一考试名称下多个班级均分对比（任课教师场景） |

#### 3.7.4 学生维度分析
| 图表 | 说明 |
|---|---|
| 个人成绩趋势折线 | 该生历次考试分数 vs 班级均分（双线对比） |
| 名次变化折线 | 历次班级排名（Y 轴反向，名次 1 在顶部） |
| 科目雷达图 | 多科目最近一次考试的标准分（Z-score 归一），任课多科时有效 |
| 稳定性指标 | 个人成绩标准差、最好/最差、平均名次 |

#### 3.7.5 导出
- 班级成绩单导出 CSV / XLSX。
- 图表导出 PNG。

**验收标准**
- AC-12：缺考学生不计入均分、及格率分母。
- AC-13：某学生仅参加 1 次考试时，趋势图正常展示单点而非报错。
- AC-14：50 人 × 20 次考试的分析页首屏出图 < 1.5s。

### 3.8 PWA 与移动端

- Web App Manifest：名称、图标（192/512）、`display: standalone`、主题色。
- Service Worker：
  - 静态资源 Cache First（带版本号，发布时失效）。
  - API 请求 Network First，失败回落最近一次缓存，并在页面顶部提示「离线数据，更新于 xx」。
  - 离线可读：班级列表、学生列表、今日日程、当前座位图。
  - 离线不可写：写操作在离线时禁用并提示（v1 不做离线队列同步）。
- 响应式断点：`< 768px` 手机布局（底部 Tab 导航），`≥ 1024px` 桌面布局（左侧导航）。
- 手机端底部导航：**首页 / 班级 / 课堂工具（抽签·分组·座位） / 成绩 / 我的**。

**验收标准**
- AC-15：Chrome Lighthouse PWA 分项全部通过，可安装到桌面。
- AC-16：飞行模式下打开已安装应用，能看到最近一次访问的班级学生名单。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 常规 API P95 < 300ms；分析类 API P95 < 800ms |
| 兼容性 | Chrome/Edge/Safari 最近两个大版本；iOS 15+ / Android 10+ |
| 安全 | HTTPS；密码 bcrypt；SQL 参数化；速率限制；CORS 白名单；越权校验 |
| 隐私 | 学生姓名、电话属个人信息，仅归属教师可见；导出需二次确认 |
| 可用性 | 单实例部署即可；数据库每日备份 |
| 可维护性 | OpenAPI 3.1 文档自动生成；核心统计逻辑单测覆盖 ≥ 80% |
| 国际化 | v1 仅简体中文，但文案集中管理便于后续扩展 |

## 5. 技术架构建议

```
┌──────────────────────────────┐
│  前端 SPA + PWA              │
│  Vue 3 + Vite + TypeScript   │
│  Pinia / Vue Router          │
│  ECharts（图表）             │
│  vite-plugin-pwa（SW）       │
└──────────────┬───────────────┘
               │ HTTPS / JSON (REST)
┌──────────────▼───────────────┐
│  后端 API                    │
│  Node.js + NestJS  (或 FastAPI) │
│  JWT 鉴权 / 参数校验         │
│  Prisma ORM                  │
└──────────────┬───────────────┘
               │
┌──────────────▼───────────────┐
│  PostgreSQL 15               │
│  （可选）Redis：限流/缓存    │
│  对象存储：头像图片          │
└──────────────────────────────┘
```

说明：
- 图表库选 **ECharts**（移动端手势、导出图片能力好）。
- 座位图拖拽用 **HTML5 Drag & Drop + Pointer Events** 兼容触屏。
- 后端若团队更熟 Python，可换 FastAPI + SQLAlchemy，API 契约不变。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 座位图拖拽在移动端体验差 | 高 | 移动端只读，编辑限桌面端 |
| 学生姓名等个人信息合规 | 高 | 数据仅归属教师；导出加水印与确认；隐私政策页 |
| 成绩统计口径争议（缺考、加分） | 中 | 明确定义并在 UI 注明口径，阈值可配置 |
| 离线写入冲突 | 中 | v1 明确不支持离线写，避免数据错乱 |
| 批量导入格式五花八门 | 中 | 提供模板下载 + 导入预览确认页 |
